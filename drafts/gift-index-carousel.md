I'm a fashion data analyst, so I can't write a gift guide on vibes alone! Every category here is something I've already measured this year, either in a year of search data or in the 997 runway looks I tagged across 16 Paris SS27 shows, and then I've added the piece I'd actually want to unwrap.

**Start with the fabric, because the label inside matters more than the logo outside**

- Cashmere +80%

Body: Searches for cashmere and cotton have almost doubled in a year, and wool suiting was in a quarter of all the looks I tagged in Paris, which is why I keep saying natural fibres are the safest thing you can give.

Body: This is the biggest jump in everything I've pulled this year, and I'll be honest that a number this size usually means it started from very little, so it could go either way, which is exactly what makes it a fun gift!
