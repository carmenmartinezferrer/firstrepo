# DFB Black Friday Reels: De-influencing (v3)

**Source:** Carmen's own picks and reasoning (no article), plus the deal research from the same session. Every number is either Carmen's own word or flagged below.

**Core argument:** AI can write a lot of the code now and will not replace data analysts, but you only get the value if you understand what it writes, so Carmen's Black Friday list is built around learning (DataCamp, a methods book, Excel), a daily AI subscription and wired headphones, with no waiting for deals that don't exist. Her second rule is that she never buys a microtrend, so zebra is out and wool or cashmere is in. The strongest receipt is DataCamp 60% off, which Carmen confirmed herself; the microtrend half is her professional opinion until a head-to-head search chart backs it.
