# Reference articles

Drop reference material here, either your own past DFB pieces (so future
drafts can match your established pacing and structure) or outside examples
whose **format** you want borrowed (never their voice, that's defined in
the root `CLAUDE.md`).

How to add something:

- Paste the full text into a Claude Code chat in this repo and ask for it to
  be saved here, that's the easiest path from a phone or browser.
- Or add the file directly to this folder if you're working from a local
  clone.

Name files so the format is obvious at a glance, e.g.
`dfb-summer-2026-macro-trend-report.md`, `external-trend-autopsy-format-example.md`.
For outside examples, note at the top of the file whose it is and what
specifically to borrow from it (structure, not tone), so nobody mistakes it
for a voice reference later.

## What's here so far

- `donut_chart_builder.py` and `DMSerifDisplay-Regular.ttf`, the saved
  Catwalk Decode donut chart spec and the font it needs. Reuse for every
  future palette, silhouette or material donut set.
